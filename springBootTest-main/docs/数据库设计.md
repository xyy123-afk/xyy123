# xyy_login 数据库设计文档

> 项目：xyy-afk-java（Spring Boot 3.4 + MyBatis-Plus + Vue3）
> 数据库：MySQL 8.x · 字符集 utf8mb4 / utf8mb4_unicode_ci · 引擎 InnoDB
> 建表脚本：[schema.sql](./schema.sql)（幂等，可重复执行，不清业务数据；`一键启动.bat` 每次启动都会执行）

## 1. 总览

| 分组 | 表 | 作用 |
|---|---|---|
| 账号 | `users` | 登录账号、昵称、头像 URL |
| 博客 | `posts`、`categories`、`tags`、`post_tags` | 文章、分类、标签及其多对多关联 |
| 互动 | `comments`、`post_likes` | 评论树、点赞 |
| 私信 | `conversations`、`messages`、`stickers` | 会话、消息、表情包收藏 |
| 其它 | `site_settings`、`links`、`images` | 站点单行配置、友链、**图片二进制** |

关系均为**逻辑关联**（`user_id` / `post_id` 等），不建物理外键——练手项目方便单独导数据、改表，正式项目建议补 `ON DELETE CASCADE`。

## 2. 图片存储（2026-11 改版重点）

以前图片落在项目根 `uploads/yyyy-MM/uuid.ext`，备份数据库不带图片、换机器部署容易丢。现在统一存 `images` 表：

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT UNSIGNED PK | 自增，URL 里用它：`/api/images/{id}` |
| content_type | VARCHAR(64) | MIME（`image/png` 等），读图时原样回给浏览器 |
| file_name | VARCHAR(255) | 原始文件名，仅备查 |
| content | **LONGBLOB** | 图片二进制本体 |
| size_bytes | BIGINT UNSIGNED | 字节数 |
| uploader_id | BIGINT UNSIGNED | 上传者，取自 `LoginInterceptor` |
| legacy_path | VARCHAR(255) **UNIQUE** | 旧 `uploads/` 相对路径，迁移去重用；新上传为 NULL |
| created_at | DATETIME | 上传时间 |

- 上传：`POST /api/upload`（需登录）→ 插入 `images` → 返回 `{ url: "/api/images/{id}" }`
- 读图：`GET /api/images/{id}` **匿名可读**（`<img>` 不带 token），带长期缓存与 `nosniff`
- 引用位置：`users.avatar`、`stickers.url`、`messages.content`（type=sticker）、文章 Markdown/HTML
- 合法地址由 `ImageUrls.isLocal()` 统一校验：只放行 `/api/images/{数字}` 和旧 `/uploads/`
- `/uploads/**` 静态映射保留做兼容；历史文件可用 `app.migrate-uploads.enabled=true` 启动一次迁移入库（幂等，见 `UploadMigrationRunner`）

> ⚠️ 别对 `images` 写「列表」查询：`content` 是 LONGBLOB，`selectList()` 会把一堆图片二进制拉回内存。只按 id 查单条。

## 3. 关键表要点

**users** — `username` 唯一索引 `uk_users_username`；`password` 存 BCrypt 密文（60 字符），绝不存明文；`avatar` 可为空。

**posts** — `status` 1 已发布 / 0 草稿，`is_top` 置顶；`content_md` 存原文、`content_html` 存渲染结果，前台直接读 HTML 不再实时渲染。

**comments** — `parent_id` 组成评论树；`status` 由后台审核。

**messages** — `type` = `text` / `sticker`（sticker 时 `content` 就是图片 URL）；`deleted` 标记 2 分钟内撤回，撤回后内容不再对外返回。

**stickers** — 按 `(user_id, id)` 索引取「我的收藏」；删收藏不影响已发送的历史消息。

**site_settings** — 单行表，`id` 恒为 1；博客名/副标题/作者等由后台「站点设置」页维护。

## 4. 常用操作

```sql
-- 建库建表（幂等，不清数据）
mysql -uroot -p --default-character-set=utf8mb4 < docs/schema.sql

USE xyy_login;
SHOW TABLES;
DESC images;

-- 图片占用（不含二进制内容）
SELECT COUNT(*) AS 张数, SUM(size_bytes)/1024/1024 AS MB FROM images;

-- 还有多少旧地址引用（应为 0）
SELECT 'users' 来源, COUNT(*) 条数 FROM users WHERE avatar LIKE '/uploads/%'
UNION ALL SELECT 'stickers', COUNT(*) FROM stickers WHERE url LIKE '/uploads/%'
UNION ALL SELECT 'messages', COUNT(*) FROM messages WHERE content LIKE '%/uploads/%';
```

# xyy_login 数据库设计文档

> 项目：xyy-afk-java（Spring Boot + MyBatis-Plus + Vue3）
> 数据库：MySQL 8.0 · 字符集 utf8mb4 · 引擎 InnoDB
> 建表脚本：[schema.sql](./schema.sql)（幂等，可重复执行，不清数据）

## 1. 总览

| 表名 | 作用 | 关键约束 |
|---|---|---|
| `users` | 用户账号（注册/登录） | username 唯一 |
| `todos` | 待办事项 | user_id 逻辑关联 users.id |

关系：`users 1 ── N todos`（一个用户多条待办）。**不建物理外键**，靠业务层保证（练手项目方便单独删数据，正式项目建议加 `ON DELETE CASCADE`）。

## 2. users 用户表

| 字段 | 类型 | 空 | 默认 | 说明 |
|---|---|---|---|---|
| id | BIGINT UNSIGNED | 否 | 自增 | 主键 |
| username | VARCHAR(32) | 否 | — | 用户名/邮箱，**唯一索引** `uk_users_username` |
| password | VARCHAR(72) | 否 | — | BCrypt 密文（固定 60 字符，长度留余量） |
| created_at | DATETIME | 否 | CURRENT_TIMESTAMP | 注册时间 |

要点：
- 密码**绝不存明文**，注册时由后端 `BCryptPasswordEncoder` 加密后写入
- username 唯一索引在数据库层兜底防重复注册（代码层先查一次）

## 3. todos 待办事项表

| 字段 | 类型 | 空 | 默认 | 说明 |
|---|---|---|---|---|
| id | BIGINT UNSIGNED | 否 | 自增 | 主键 |
| user_id | BIGINT UNSIGNED | 否 | — | 所属用户 id，**普通索引** `idx_todos_user_id` |
| content | VARCHAR(255) | 否 | — | 待办内容（前后端都校验 ≤255） |
| done | TINYINT(1) | 否 | 0 | 0 未完成 / 1 已完成 |
| due_date | DATETIME | 是 | NULL | 截止日期（前端暂未用，字段已预留） |
| priority | TINYINT | 否 | 0 | 0 普通 / 1 重要 / 2 紧急（前端暂未用） |
| created_at | DATETIME | 否 | CURRENT_TIMESTAMP | 创建时间 |

要点：
- `idx_todos_user_id`：列表页固定按 user_id 查询，走索引
- done / priority 用 TINYINT 而非 ENUM，改值不用改表结构

## 4. 常用操作

```sql
-- 建库建表（幂等）
mysql -uroot -p < docs/schema.sql

-- 查看结构
USE xyy_login; SHOW TABLES; DESC users; DESC todos;

-- 查某用户的待办
SELECT t.id, t.content, t.done, t.created_at
FROM todos t JOIN users u ON t.user_id = u.id
WHERE u.username = 'demo001' ORDER BY t.id DESC;

-- 统计（对应 GET /api/todos/stats 的逻辑）
SELECT COUNT(*) 总数,
       SUM(done = 1) 已完成,
       SUM(done = 0) 未完成
FROM todos WHERE user_id = 1;
```

## 6. 后续扩展建议（对应首页规划的功能）

| 功能 | 需要的改动 |
|---|---|
| 待办搜索 | content 加 `FULLTEXT` 或 `LIKE` 前缀索引（数据量小 LIKE 够用） |
| 个人资料 | users 加 nickname / avatar_url 字段 |
| 待办统计页 | 现有字段够用，无需改表 |
